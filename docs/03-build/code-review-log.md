- `pane rename`(label)과 `agent rename`(name)이 별개임을 확인 — `tell.py`는 `name`으로 조회하므로 **둘 다** 설정해야 함. `team_up.py`에 반영.

> ⚠️ **한계 명시**: 이 판정은 PM이 직접 수행한 것으로, CHARTER §2의 역할 분리 원칙상 정식 판정이 아니다.
