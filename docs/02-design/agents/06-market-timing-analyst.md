# 06. `market-timing-analyst` — 타이밍 분석가 (2차)

> 공통 규약: [`README.md`](README.md)
> 담당 요구사항: **F3**(언제 사야 하는지) — 인터뷰에서 사용자가 꼽은 핵심 문제 ③

## 목적
"지금 사야 하나, 6개월 기다려야 하나"에 **근거 있는 신호**를 준다.
가격을 예측하는 게 아니라, **지금이 어떤 국면인지**를 지표로 설명한다.

## ⛔ 이 에이전트가 하지 않는 것
- **가격 예측 금지.** "내년에 5% 오릅니다" 같은 출력은 금지다.
- 매수·매도 **권유 금지.** 국면 판정과 근거까지가 한계다.

> 부동산 가격 예측은 신뢰할 수 있는 방법이 없다. 예측을 내놓는 순간 이 제품은
> 근거 도구가 아니라 점집이 된다. **국면 판정**과 **예측**은 다르다.

## 판단 로직 — 지표 기반 규칙 (LLM은 설명만)

| 지표 | 출처 | 해석 방향 |
|---|---|---|
| **전세가율** | 부동산원 | 높을수록 매매 하방 지지 ↑ (실수요 뒷받침) |
| **미분양** | 국토부 | 증가 = 공급 과잉 신호 |
| **매수우위지수** | 부동산원 | 100 초과 = 매수자 우위(살 때 유리) |
| **입주물량** | 국토부 | 향후 6~12개월 물량 많으면 전세·매매 약세 압력 |
| **기준금리** | 한국은행 | 상승기 = 대출 부담 ↑ |
| 거래량 | 실거래 집계 | 바닥 대비 회복 여부 |

### 국면 판정
```
score = Σ (지표 z-score × 방향계수 × 가중치)
```
| score | signal | 문구 |
|---|---|---|
| 상위 | `buy_favorable` | 매수자에게 유리한 구간 |
| 중간 | `neutral` | 뚜렷한 신호 없음 |
| 하위 | `wait` | 관망 우세 구간 |

**지역 단위로 판정한다.** 수도권 전체 평균은 의미가 없다 — 강남과 인천은 다른 시장이다.

## 출력
```json
{
  "agent_id": "market-timing-analyst",
  "region_code": "1168000000",
  "signal": "buy_favorable",
  "score": 68.2,
  "indicators": [
    { "name": "매수우위지수", "value": 88.4, "as_of": "2026-06-30",
      "direction": "매도자 우위", "source": "한국부동산원" },
    { "name": "전세가율", "value": 0.523, "as_of": "2026-06-30", "source": "한국부동산원" },
    { "name": "입주물량(향후 12개월)", "value": 3120, "unit": "세대", "source": "국토교통부" }
  ],
  "verdict": "매수 우위 구간 진입",
  "rationale": "매수우위지수 88.4로 매수자 협상력이 있는 구간이며, 향후 12개월 입주물량 3,120세대로 공급 압력이 있습니다. 다만 전세가율 52.3%는 하방 지지가 강하지 않은 수준입니다.",
  "evidence": [ { "claim": "매수우위지수 88.4", "source": "한국부동산원",
                  "as_of": "2026-06-30" } ],
  "confidence": 0.65,
  "risks": [
    { "severity": "high",
      "detail": "시장 지표는 과거·현재 상태를 나타낼 뿐 미래 가격을 보장하지 않습니다" },
    { "severity": "medium", "detail": "지표 발표는 1~2개월 시차가 있습니다" }
  ]
}
```

> `confidence`를 0.7 이상으로 올리지 않는다. 시장 국면 판정은 본질적으로 불확실하다.

## 데이터 의존
`market_index`, `trade`(거래량 집계), `region`

## 검증 포인트 (re-review)
- [ ] 가격 예측 표현이 없는가
- [ ] 매수/매도 **권유** 표현이 없는가
- [ ] 지역 단위로 판정하는가 (수도권 일괄 아님)
- [ ] 모든 지표에 `as_of`와 출처가 있는가
- [ ] `confidence ≤ 0.7`인가
- [ ] "예측이 아니다"라는 리스크 고지가 항상 포함되는가
