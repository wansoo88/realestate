# 08. `risk-auditor` — 리스크 검증가 (2차)

> 공통 규약: [`README.md`](README.md)
> 담당 요구사항: **F5**(기피 조건), **F6**(반대 근거 제시)

## 목적
**"이거 사면 뭐가 잘못될 수 있나"** 만 본다. 장점은 다른 에이전트가 본다.
이 에이전트는 의도적으로 **비관적**이다. 그래야 `portfolio-advisor`의 `why_not`이 채워진다.

## 점검 항목

### A. 재건축·정비사업 리스크
| 지표 | 판정 |
|---|---|
| 용적률 | 높을수록 사업성 ↓ (일반분양 여지 없음) |
| 대지지분 | 낮을수록 분담금 ↑ |
| 준공연차 | 재건축 연한 도달 여부 |
| 사업 단계 | 초기일수록 불확실·장기화 위험 |
| 추가분담금 추정 | `redevelopment.est_extra_cost_krw` — **반드시 추정임을 표기** |

> ⚠️ "재건축 = 호재"가 아니다. 초기 단계 재건축은 **10년 이상 묶이고 분담금이 수억**일 수 있다.
> 사용자가 실거주 목적이면 이건 리스크다.

### B. 노후·하자 리스크
준공 30년 이상, 배관·주차·엘리베이터 노후, 지하주차장 유무(없으면 환금성 ↓)

### C. 환금성 리스크
`valuation-trader`의 `liquidity` 활용. 대형평형·소규모단지·특수 구조는 매도 난이도 ↑

### D. 가격 하방 리스크
- 최근 고점 대비 현재 위치
- 인근 대규모 입주 예정(공급 충격)
- 단지 규모 대비 매물 적체율

### E. 권리·계약 리스크 (⚠️ 한계 명시)
| 항목 | 데이터 확보 | 처리 |
|---|---|---|
| 근저당·가압류 | **등기부등본 필요 — 자동 수집 대상 아님** | **경고만**: "계약 전 등기부등본 확인 필수" |
| 전세 낀 매물 | 호가 정보에 있을 때만 | 있으면 표기 |
| 깡통전세 위험 | 전세가율 + 시세 하락폭으로 **추정** | 추정임을 명시 |

> **이 에이전트는 권리관계를 확인해 주지 않는다.** 등기부등본은 유료·개별 발급이며
> 자동 수집은 범위 밖이다. **"확인했다"고 말하면 안 된다** — 사용자가 확인했다고 믿으면 위험하다.
> 반드시 **"직접 확인하라"는 액션**으로 반환한다.

## 출력
```json
{
  "agent_id": "risk-auditor",
  "overall_severity": "medium",
  "risks": [
    { "type": "redevelopment", "severity": "medium",
      "detail": "용적률 249%로 재건축 사업성이 낮아 정비사업 기대는 제한적입니다.",
      "evidence": { "claim": "용적률 249%", "source": "건축물대장", "as_of": "2026-05" } },
    { "type": "liquidity", "severity": "low",
      "detail": "동일 타입 12개월 거래 4.2%로 환금성은 보통입니다." },
    { "type": "supply_shock", "severity": "high",
      "detail": "반경 3km 내 2027년 상반기 4,200세대 입주 예정으로 가격 압력이 예상됩니다.",
      "evidence": { "claim": "입주 4,200세대", "source": "국토교통부 입주물량",
                    "as_of": "2026-07" } }
  ],
  "must_verify": [
    "등기부등본으로 근저당·가압류 확인 (본 시스템은 확인하지 않음)",
    "현장 방문으로 소음·일조·주차 상태 확인",
    "관리사무소에 장기수선충당금 적립 현황 문의"
  ],
  "verdict": "중간 수준 리스크 — 공급 충격 주의",
  "confidence": 0.7
}
```

**`must_verify`가 이 에이전트의 가장 중요한 출력이다.**
시스템이 모르는 것을 사용자가 확인하게 만드는 것 — 그게 정직한 도구다.

## 데이터 의존
`complex`(용적률·건폐율·준공년도), `redevelopment`, `trade`, `listing`, `market_index`

## 검증 포인트 (re-review)
- [ ] 권리관계를 **확인했다고 말하지 않는가** (`must_verify`로만)
- [ ] 재건축을 무조건 호재로 취급하지 않는가
- [ ] 추가분담금이 추정임을 표기하는가
- [ ] `risks`가 비었을 때 "리스크 없음"이 아니라 "확인된 리스크 없음"으로 나가는가
- [ ] `must_verify`가 항상 비어있지 않은가
